# AI 서류 깔끔정리

> 한 번 입력하면, 기관마다 다른 서류 양식에 알아서 채워 주는 서비스

강의 후 제출하는 강사료·인건비 서류처럼 **기관마다 양식은 다르지만 들어가는 내용은 비슷한 서류**를 자동으로 채우고, **말하듯 쭉 쓴 회의 내용을 보고서로** 정리해 주는 웹 서비스입니다.
회원 가입 없이 쓰고, AI·유료 서비스를 쓰지 않아 **운영 비용이 0원**입니다.

| 상태 | 1·2·3단계 개발 완료 (2026-10-12) |

## 1. 실행하기

두 서버를 각각 켭니다. 사이트만 켜도 PDF를 뺀 모든 기능을 쓸 수 있습니다.

```bash
node server.js
```

```bash
node converter/server.js
```

→ 홈페이지 http://localhost:5173 · PDF 변환 서버 http://localhost:8080

- 별도 설치·빌드는 필요 없습니다 (Node.js만 있으면 됨). JSZip·SheetJS·글꼴은 CDN에서 불러옵니다.
- PDF 변환 서버는 **한글이 설치된 Windows PC**에서 한글로 직접 PDF를 만듭니다 (아래 4장).
- Claude 앱의 미리보기에서는 `.claude/launch.json`의 `site`·`pdf` 설정으로 켤 수 있습니다.

## 2. 기능

### ① 강의 서류 자동 채우기

기관에서 받은 빈 한글 양식(`.hwpx`)에 강의 정보·내 정보·서명을 넣습니다.

1. **양식 올리기** — `.hwpx`를 끌어다 놓기. 구형 `.hwp`를 올리면 "한글에서 다른 이름으로 저장 → 한글 표준 문서(*.hwpx)" 방법을 보여 줌
2. **강의 정보** — 강의명·날짜·시간·내용 + 내 정보(강사명·소속·연락처·이메일·작성일) + 강사료 지급 정보(주민등록번호·은행명·계좌번호)
3. **서명** — 흰 종이에 한 서명 사진을 올리면 배경을 투명하게 바꾸고 여백을 잘라 냄
4. **칸 확인** — 자동으로 찾은 칸을 보여 주고, 틀린 칸은 직접 고르기 ('자동' / '확인 필요' 표시)
5. **받기·보내기** — `.hwpx` 받기, PDF로 받기, Gmail 쓰기 창 열기

**칸 찾기 단어** ([js/hwpx.js](js/hwpx.js)의 `FIELDS`)

| 항목 | 양식에서 찾는 단어 (예시) |
|---|---|
| 강의명 | 강의명, 교육명, 과정명, 프로그램명, 강좌명, 과목명, 주제 |
| 날짜 | 강의일자, 교육일자, 일시, 일자, 날짜, 교육기간 |
| 시간 | 강의시간, 교육시간, 시간, 시수 |
| 내용 | 강의내용, 교육내용, 주요내용, 세부내용, 내용 |
| 서명 | 서명, 강사 서명, 본인서명, 날인 → 옆 칸에 "강사명 (인)" + **서명 그림을 (인) 위에 도장처럼 겹침** (이름은 끌 수 있고, 칸에 이미 이름이 있으면 넣지 않음) |
| 내 정보 | 강사명·성명·예금주, 소속, 연락처, 이메일, 작성일·신청일 |
| 지급 정보 | 주민등록번호·주민번호, 은행명·거래은행·입금은행, 계좌번호·입금계좌 |

- 표 밖에 있는 **"성명 :      (인)" 같은 서명 줄**도 찾아서 이름과 서명을 넣습니다. 이름 자리에 누름틀(클릭하여 입력)이 있으면 그 안에 넣습니다.
- 칸 이름의 **오른쪽 칸**(없으면 아래 칸)이 비어 있거나 "년 월 일", "(인)" 같은 자리 표시만 있을 때 채웁니다.
- 원본 양식의 글꼴·표·그림은 그대로 두고, 채운 칸과 서명만 바꿉니다.
- 양식에 은행명 칸 없이 "입금계좌" 칸만 있으면 "KB국민은행 000-0000-0000"처럼 한 칸에 함께 넣습니다.
- **주민등록번호**는 입력할 때 ●●●로 가리고([보기]로 확인), 숫자 13자리를 넣으면 가운데 "-"를 자동으로 넣습니다. **"주민등록번호도 기억하기"를 따로 켰을 때만** 브라우저에 저장합니다 (기본은 저장 안 함).

### ② Gmail로 보내기

- 저장해 둔 받는 사람(기관 이름 + 이메일)을 고르면 Gmail 쓰기 창이 열리고 **받는 사람·제목·본문**이 채워집니다.
- `https://mail.google.com/mail/?view=cm&fs=1&to=…&su=…&body=…` 링크 방식이라 **첨부파일은 자동으로 넣을 수 없습니다.** 받은 서류를 직접 첨부해야 합니다.

### ③ 회의록 정리

말하듯 쭉 쓴 회의 내용을 **보고서 형식**으로 나누고, 말투를 **보고서 문구**로 바꿉니다. AI 없이 정해 둔 규칙으로 브라우저 안에서만 정리합니다.

- **입력**: 직접 쓰기, 붙여넣기, `.txt` / `.docx` 불러오기, 샘플 회의록
- **보고서 구성**: 1. 회의 개요 / 2. 주요 논의 내용 / 3. 결정 사항 / 4. 향후 조치 계획(표) / 5. 건의 및 이슈
- **회의 정보 찾기**: 첫 줄 "10월 12일 강사 운영 회의" → 회의명·일시, `참석:` `장소:` `작성자:` 줄
- **문장 나누기**: 담당자가 있거나 기한 + 행동이면 할 일, "결정·하기로 함"이면 결정, "문제·부족·고장"이면 이슈, 나머지는 논의
- **담당자**: 참석자 이름, `담당: 이름`, "김팀장님이"처럼 직함 + 조사
- **기한**: "10월 15일까지", "10/20까지", "이번 주 금요일까지", "다음 주까지", "월말까지" → 회의 날짜 기준으로 실제 날짜 계산

| 쓴 문장 | 보고서 문구 |
|---|---|
| 반응이 엄청 좋았어요 | 반응이 매우 좋았음 |
| 근데 실습 시간이 좀 부족하다는 얘기가 많았음 | 다만 실습 시간이 다소 부족하다는 의견이 많았음 |
| 실습 시간을 30분 늘리기로 했어요 | 실습 시간을 30분 늘리기로 함 |
| 설문 링크는 이매니저가 이번 주 금요일까지 보낼게요 | 할 일 "수강생 설문 링크 발송" · 담당 이매니저 · 10. 16.(금) |
| 수리 요청해야 할 것 같아요 | 수리 요청할 필요가 있는 것으로 보임 |
| 자료를 미리 받으면 좋겠어요 | 자료를 미리 받는 것이 바람직함 |

- **정리 확인**: 문장마다 들어갈 곳(논의·결정·할 일·이슈·빼기)과 문구·담당자·기한을 고칠 수 있고, 회의 내용을 더 써도 고친 값은 유지됩니다.
- **받기**: 한글 보고서(`.hwpx`), PDF, 엑셀(`.xlsx`: "할 일" + "회의 결과" 시트), 보고서 글 복사
- 말투 규칙은 [js/minutes.js](js/minutes.js)의 `WORDS`·`ENDINGS`에 있습니다. 자주 쓰는 말투가 안 바뀌면 여기에 추가합니다.

### ④ 그 밖에

- **샘플 데모**: 빈 양식에 글자가 써지고 서명·도장이 찍히는 애니메이션 (Before / After)
- **브라우저 저장**: 내 정보(은행명·계좌번호 포함)·최근 강의 정보·서명·이메일 주소를 이 브라우저(localStorage)에만 저장, 주민등록번호는 따로 켰을 때만 저장, 맨 아래 버튼으로 한 번에 지우기

## 3. 개인정보와 비용

| 원칙 | 내용 |
|---|---|
| 서류는 브라우저 안에서 | 양식 읽기·채우기, 서명 배경 제거, 회의록 정리는 모두 브라우저 안에서 합니다 |
| 예외는 PDF 하나 | [PDF로 받기]를 누를 때만 서류가 변환 서버로 가고, 변환 직후 임시 파일을 지웁니다 |
| 주민등록번호 | 기본은 저장하지 않음. 켰을 때만 이 브라우저에 저장하고, 서버로 보내지 않음 (PDF 변환 때 서류에 담겨 변환 서버를 거쳤다가 바로 지워짐) |
| 로그인 없음 | 추가 비용을 쓰지 않기로 해 구글·카카오 로그인과 계정 저장은 넣지 않았습니다 |
| 비용 0원 | 유료 API·클라우드를 쓰지 않습니다 (회의록 정리도 AI 대신 규칙) |

## 4. PDF 변환 서버

홈페이지는 서버가 켜져 있으면 **[PDF로 받기]**를 켜고, 꺼져 있으면 "한글에서 PDF로 저장" 안내를 엽니다. 엔진은 자동으로 고릅니다 (Windows → 한글, 그 외 → LibreOffice, 직접 정하려면 `ENGINE=hangul` / `ENGINE=libreoffice`).

| 방식 | 실행 | 결과 | 확인 |
|---|---|---|---|
| **한글 (권장)** | `node converter/server.js` | 한글로 직접 저장 → 원본과 같은 모양, 약 4~5초 | 한글 2022에서 확인 |
| Docker | `docker build -t doc-clean-pdf converter` 후 `docker run -d -p 8080:8080 doc-clean-pdf` | LibreOffice + H2Orestart → 글꼴·줄 간격이 조금 다를 수 있음 | 아직 실행해 보지 않음 |

- `GET /health` → `{ ok, engine }`, `POST /convert` → 본문 `.hwpx`, 응답 PDF (20MB까지, 90초 제한, 한 번에 하나씩)
- 서버 주소는 [js/config.js](js/config.js)의 `pdfServer`에서 바꿉니다. 배포할 때는 `ALLOW_ORIGIN`을 홈페이지 주소로 좁힙니다.
- 홈페이지가 사용자 PC의 한글을 직접 실행하는 것은 브라우저 보안상 불가능해서, 변환은 서버가 맡습니다.

## 7. 알아 둘 한계

- **실제 기관 양식으로는 아직 시험하지 않았습니다.** 칸 이름이 다르면 못 찾을 수 있어 '칸 확인'에서 직접 고르게 했습니다.
- 표가 아닌 자유 형식 양식("교육명: ____")은 칸을 찾지 못합니다.
- 구형 `.hwp`는 바로 처리할 수 없습니다 → 한글에서 `.hwpx`로 저장 후 사용
- Gmail 링크로는 첨부파일을 넣을 수 없습니다 → 받은 서류를 직접 첨부
- PDF 자동 변환은 **한글이 설치된 PC에서 변환 서버를 켜 두어야** 합니다. Docker 방식은 코드만 있고 실행해 보지 않았습니다.
- 회의록 정리는 규칙 방식이라 규칙에 없는 말투("괜찮던데" 등)는 그대로 남거나 잘못 나뉠 수 있습니다 → '정리 확인'에서 고치기
- 브라우저 저장이라 다른 PC·브라우저에서는 서명과 정보를 다시 넣어야 합니다.
- 공용 PC에서는 "기억하기"를 끄고, 다 쓴 뒤 [저장된 정보 모두 지우기]를 눌러야 합니다. 브라우저 저장은 암호화되지 않습니다.
