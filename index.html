      자주 묻는 질문

      궁금한 점

      구형 한글 파일(.hwp)은 안 되나요?

      .hwp는 웹에서 바로 고칠 수 없는 형식이에요. 한글에서 파일 → 다른 이름으로 저장하기 → 한글 표준 문서(*.hwpx)로 한 번만 저장해서 올려 주세요.

      서명 사진이 어딘가에 저장되나요?

      회원 가입 없이 쓰는 서비스라, 서명은 이 브라우저 안에만 저장돼요. 다른 PC나 다른 브라우저에서는 서명을 한 번 더 올려 주세요. [PDF로 받기]를 누르면 서명이 들어간 서류가 변환 서버로 갔다가 변환이 끝나면 바로 지워져요.

      주민등록번호와 계좌번호는 어디에 저장되나요?

      양식을 채우는 데만 쓰고 서버로 보내지 않아요. 계좌번호는 다른 내 정보처럼 이 브라우저에 기억하고, 주민등록번호는 '주민등록번호도 기억하기'를 켰을 때만 저장해요. 공용 PC에서는 켜지 말고, 다 쓴 뒤 맨 아래 [저장된 정보 모두 지우기]를 눌러 주세요. 단, [PDF로 받기]를 누르면 채운 서류가 PDF 변환 서버를 거쳤다가 바로 지워져요.

      양식의 칸을 잘못 찾으면 어떻게 하나요?

      '칸 확인' 단계에서 칸마다 넣을 항목을 직접 고르거나 '넣지 않음'으로 바꿀 수 있어요. 표가 아닌 자유 형식 양식은 칸을 찾지 못할 수 있어요.

      Gmail에 첨부파일이 자동으로 들어가나요?

      아니요. Gmail 링크로는 첨부파일을 넣을 수 없어서, 받는 사람·제목·본문까지만 채워져요. 받은 서류는 직접 첨부해 주세요.

      회의록 정리는 AI가 하나요?

      아니요. 정해 둔 규칙으로 문장을 나누고 말투를 보고서 문구로 바꿔서 비용이 들지 않고, 회의 내용도 이 브라우저 밖으로 나가지 않아요([PDF로 받기]를 누를 때만 변환 서버를 거쳐요). 대신 자유롭게 쓴 문장은 잘못 나눌 수 있으니 '정리 확인'에서 고쳐 주세요.

      PDF로 받을 수 있나요?

      네. 변환 서버가 켜져 있으면 [PDF로 받기]를 눌러 바로 받을 수 있어요. 한글이 설치된 PC에서 돌리는 변환 서버는 한글로 직접 PDF를 만들어 원본과 같아요. 변환 서버가 꺼져 있으면 받은 .hwpx를 한글에서 파일 → PDF로 저장하기로 저장해 주세요.
